성능 최적화, UX 개선, 접근성 향상, 코드 품질 개선을 위한 프롬프트 모음입니다.

## 성능 최적화

### IMP-P01: 데이터베이스 쿼리 최적화

**목적:** N+1 문제 해결 및 쿼리 성능 개선

**필수 컨텍스트:**
- 느린 엔드포인트/페이지
- 현재 쿼리 패턴
- 예상 데이터 규모

**프롬프트:**
```
InterfaceHive [엔드포인트/페이지]의 데이터베이스 쿼리를 최적화해줘.

## 현재 상황
- 위치: [파일 경로]
- 문제: [느린 로딩/N+1 쿼리/과도한 쿼리 수]
- 현재 쿼리 수: [예상 숫자]

## 분석 요청
1. django-debug-toolbar 또는 EXPLAIN ANALYZE로 병목 식별
2. N+1 쿼리 패턴 찾기
3. 불필요한 필드 로딩 확인

## 최적화 방법
- select_related: [ForeignKey 관계]
- prefetch_related: [ManyToMany/역참조]
- only/defer: [필요/불필요 필드]
- 인덱스 추가: [자주 필터링되는 필드]

## 제약조건
- 기존 기능 유지
- 쿼리 결과 동일해야 함
- 최적화 전후 비교 가능하게
```

**예시:**
```
InterfaceHive 프로젝트 목록 API의 쿼리를 최적화해줘.

## 현재 상황
- 위치: apps/projects/views.py - ProjectViewSet.list()
- 문제: 프로젝트 100개 조회 시 200+ 쿼리 발생
- 원인: 각 프로젝트의 host_user, contributions를 개별 조회

## 최적화 대상
- host_user: select_related 적용
- contributions_count: annotate로 집계
- latest_contribution: Prefetch로 최신 1개만
```

```typescript

- Record, Extract, Exclude
- 커스텀 유틸리티

- CRITICAL: 시스템 장애
