# 아이디에이션 프롬프트 (Ideation Prompts)

새로운 기능 브레인스토밍, 기술 솔루션 탐색, 경쟁사 분석, 사용자 피드백 기반 개선을 위한 프롬프트 모음입니다.

---

## 기능 브레인스토밍

### IDEA-B01: 새 기능 아이디어 생성

**목적:** 새로운 기능 아이디어 발굴

**프롬프트:**
```
InterfaceHive의 [목표/영역]을 위한 새로운 기능 아이디어를 제안해줘.

## InterfaceHive 개요
- 플랫폼: 오픈소스 기여 마켓플레이스
- 핵심 가치: 프로젝트 호스트와 기여자 연결, 크레딧 기반 평판
- 주요 사용자: 프로젝트 호스트, 기여자, 관리자

## 브레인스토밍 목표
- 영역: [참여 증대/수익화/커뮤니티/게이미피케이션/...]
- 목표 사용자: [호스트/기여자/신규 사용자]
- 제약: [기술적/비즈니스적 제약]

## 요청 사항
1. 최소 5개 아이디어 제안
2. 각 아이디어에 대해:
   - 기능 설명 (1-2문장)
   - 해결하는 문제
   - 예상 효과
   - 구현 복잡도 (낮음/중간/높음)

## 평가 기준
- 사용자 가치
- 차별화
- 구현 가능성
- 기존 기능과의 시너지
```

**예시:**
```
InterfaceHive의 기여자 참여 증대를 위한 새로운 기능 아이디어를 제안해줘.

## 브레인스토밍 목표
- 영역: 게이미피케이션, 소셜 기능
- 목표 사용자: 기여자 (특히 신규)
- 제약: MVP 수준으로 2주 내 구현 가능해야 함
```

## 현재 기능

- 현재 동작: [동작 설명]
- 위치: [파일 경로 또는 URL]

## 알려진 문제점
- [문제1]
- [문제2]

## 사용자 피드백 (있다면)

## 요청 사항

## 우선순위 기준

### IDEA-B03: 워크플로우 개선 아이디어

**목적:** 사용자 여정 최적화

**프롬프트:**
```
InterfaceHive [사용자유형]의 [워크플로우명] 워크플로우 개선 아이디어를 제안해줘.

## 현재 워크플로우
1. [단계1]
2. [단계2]
3. [단계3]
...

## 측정 지표 (있다면)
- 완료율: [%]
- 평균 소요 시간: [분]
- 이탈 지점: [단계]

## 요청 사항
1. 단계 간소화 기회
2. 자동화 가능 부분
3. 가이드/온보딩 개선
4. 에러 방지/복구 개선

## 벤치마크
- 유사 서비스: [서비스명]
- 참고할 패턴: [패턴]
```

**예시:**
```
InterfaceHive 기여자의 "프로젝트 발견 → 기여 신청" 워크플로우 개선 아이디어를 제안해줘.

## 현재 워크플로우
1. 프로젝트 목록 탐색
2. 프로젝트 상세 확인
3. 기여 신청 버튼 클릭
4. 메시지 작성
5. 제출

## 문제점
- 프로젝트 찾기 어려움
- 어떤 프로젝트가 나에게 맞는지 모름
- 메시지 작성에 대한 가이드 없음
```
