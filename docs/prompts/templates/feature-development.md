## Phase 1: 요구사항 분석

### 프롬프트

```

## 기능 개요
- 기능명: [기능명]
- 목적: [어떤 문제를 해결하는지]
- 대상 사용자: [호스트/기여자/관리자]

## 요구사항
### 필수 (Must Have)
- [필수 요구사항 1]
- [필수 요구사항 2]

### 선택 (Nice to Have)
- [선택 요구사항 1]

## 질문
1. 이 기능을 위해 필요한 데이터 모델은?
2. 기존 시스템과의 통합 포인트는?
3. 잠재적 보안 고려사항은?
4. 성능에 미치는 영향은?

## 현재 코드베이스
- 관련 앱: apps/[앱이름]/
- 관련 컴포넌트: src/[경로]/

요구사항을 분석하고 구현 계획을 제안해줘.
```

## 빠른 시작 (Quick Start)

전체 기능을 한 번에 요청할 때:

```
InterfaceHive에 [기능명] 기능을 구현해줘.

## 기능 설명
[상세 설명]

## 요구사항
- [요구사항 1]
- [요구사항 2]
- [요구사항 3]

## 기술 스택
- 백엔드: Django 6.0.1 + DRF 3.14, PostgreSQL 16
- 프론트엔드: React 19 + TypeScript, TanStack Query, shadcn/ui

## 구현 순서
1. Django 모델 및 마이그레이션
2. Serializer 및 ViewSet
3. URL 등록
4. 프론트엔드 API 클라이언트
5. TanStack Query 훅
6. 페이지 컴포넌트
7. 테스트

## 제약조건
- 직접 요청된 변경만 수행
- 기존 패턴 따르기
- 과도한 추상화 피하기
- CLAUDE.md 컨벤션 준수

각 단계별로 파일을 생성하고, 완료 후 다음 단계 진행해줘.
```
